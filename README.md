# MoexMcp

MCP-сервер для Московской биржи (MOEX). Предоставляет LLM-агентам (Claude, OpenAi, Kimi, Z.ai, deepseek и др.)
инструменты для работы с рыночными данными: акции, облигации, валюты, драгметаллы, индексы и новости.

Данные берутся из открытого API [ISS MOEX](https://iss.moex.com/iss) — ключ не требуется.
Котировки кэшируются в Redis, снапшоты рынка накапливаются фоновым воркером для сравнений за прошлые периоды.

## Возможности

- **Акции** (TQBR): котировки, топы роста/падения, поиск бумаг
- **Облигации** (ОФЗ TQOB + корпоративные TQCB): котировки с доходностью (YTM) и НКД, топы
- **Валюты**: USD/RUB, EUR/RUB (CETS)
- **Драгметаллы**: золото и серебро (GLDRUB_TOM, SLVRUB_TOM), ₽/грамм
- **Индексы**: IMOEX, RTSI
- **История**: OHLC-свечи и дневные закрытия для любого класса активов
- **Сравнение**: доходность инструментов за период, ранжирование рынка по накопленным снапшотам
- **Новости** с сайта MOEX
- **Учёт торговых сессий**: вне сессии инструменты отдают цену последней сессии
  (фолбэк `LAST → MARKETPRICE → PREVPRICE`) и явно помечают статус рынка
  («Торги идут» / «Вне сессии, данные на закрытие …»)

## Инструменты MCP

| Инструмент | Описание |
|---|---|
| `get_stock_info` | Текущая котировка акции: цена, изменение, объём, статус рынка |
| `get_top_gainers` / `get_top_losers` | Топ растущих/падающих акций за сегодня |
| `get_bond_info` | Котировка облигации: цена в % от номинала, доходность, НКД |
| `get_top_bond_gainers` / `get_top_bond_losers` | Топ растущих/падающих облигаций за сегодня |
| `get_currency_rates` | Курсы USD/RUB, EUR/RUB |
| `get_metal_prices` | Цены на золото и серебро, ₽/грамм |
| `get_indices` | Значения индексов IMOEX, RTSI |
| `search_stocks` | Поиск ценных бумаг по названию или тикеру |
| `get_moex_news` | Последние новости с сайта MOEX |
| `get_candles` | OHLC-свечи (параметр `asset_type`: `share`/`bond`/`currency`/`metal`) |
| `get_price_history` | Дневные цены закрытия за период (параметр `asset_type`) |
| `compare_instruments` | Сравнение инструментов одного класса по доходности за период |
| `rank_by_performance` | Ранжирование рынка по доходности (по снапшотам, хранятся 7 дней) |

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Redis (по умолчанию `localhost:6379`)
- Seq (опционально, для логов — по умолчанию `http://localhost:5341`)

Быстрый старт инфраструктуры через Docker:

```bash
docker run -d --name redis -p 6379:6379 redis:7
docker run -d --name seq -e ACCEPT_EULA=Y -p 5341:80 datalust/seq
```

## Запуск

```bash
dotnet run --project src/MoexMcp.Host
```

Сервер поднимется на `http://localhost:5099`, MCP-эндпоинт — `http://localhost:5099/mcp`
(HTTP-транспорт, stateless-режим).

## Подключение MCP-клиента

Пример конфигурации клиента (Claude Desktop, Kimi Code и т.п.):

```json
{
  "mcpServers": {
    "moex": {
      "url": "http://localhost:5099/mcp"
    }
  }
}
```

## Конфигурация

`src/MoexMcp.Host/appsettings.json`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `Urls` | `http://localhost:5099` | Адрес сервера |
| `Moex:BaseUrl` | `https://iss.moex.com/iss` | Базовый URL ISS MOEX |
| `Redis:ConnectionString` | `localhost:6379,password=password` | Строка подключения к Redis |
| `Seq:Url` | `http://localhost:5341` | Адрес Seq для логов |
| `Snapshots:IntervalMinutes` | `5` | Интервал сохранения снапшотов рынка |
| `Snapshots:RetentionDays` | `7` | Срок хранения снапшотов |

Все параметры можно переопределить переменными окружения
(`Moex__BaseUrl`, `Redis__ConnectionString` и т.д.).

## Архитектура

Решение разделено на слои (Clean Architecture):

```
src/
├── MoexMcp.Domain/          # Модели, интерфейсы репозиториев, TradingSchedule
├── MoexMcp.Application/     # Сервисы: MarketData, History, Comparison (кэширование)
├── MoexMcp.Infrastructure/  # ISS MOEX API (MoexRepository, IssParser), Redis, воркер снапшотов
└── MoexMcp.Host/            # ASP.NET Core хост, MCP-инструменты, DI
tests/
└── MoexMcp.Tests/           # xUnit-тесты всех слоёв
```

Ключевые механизмы:

- **Кэширование**: котировки — 30 с, списки бумаг — 60 с, новости — 5 мин,
  дневная история — 24 ч (неизменна). Слой Application не знает, что кэш — это Redis.
- **Снапшоты рынка**: `MarketSnapshotWorker` каждые 5 минут сохраняет объединённый
  снапшот (акции + облигации + металлы) в Redis (sorted-set + JSON). Опрос каждого
  класса активов ведётся только в его торговую сессию (акции 9:50–23:50, облигации
  9:50–18:40, валюта/металлы 10:00–23:50 МСК), дедупликация — по биржевому времени
  данных (`SYSTIME`) отдельно для каждого класса, поэтому праздники и неторговые дни
  не создают дублей, а торговые выходные не теряются.
- **Парсинг ISS**: доступ к ячейкам ответа строго по именам колонок
  (`IssParser`) — порядок колонок в ISS не гарантирован.

## Разработка

```bash
dotnet build MoexMcp.slnx   # сборка
dotnet test MoexMcp.slnx    # тесты
```

Соглашения: комментарии и сообщения инструментов — на русском; доступ к полям ISS —
по именам колонок; новые классы активов добавляются через `AssetClass` и маршрутизацию
в `MoexRepository`.

## Ограничения

- Смешанное сравнение классов в одном вызове `compare_instruments` не поддерживается
  (разные единицы цены: ₽, % номинала, ₽/г).
- `rank_by_performance` по облигациям начинает работать по мере накопления снапшотов
  после запуска сервера; для более ранних дат используйте `compare_instruments`
  (данные из дневной истории ISS).
- Фьючерсы и опционы (срочный рынок) не поддерживаются.
